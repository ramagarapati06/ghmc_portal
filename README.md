# Smart GHMC — Role-Based Frontend

Frontend-only Smart GHMC Complaint Management System for the assignment.

## Separate portals
Citizen:
- Login
- Citizen dashboard
- Report complaint
- Upload image
- My complaints
- Search/filter
- Track complaint
- Feedback / reopen

Admin / Officer:
- Separate login
- Command centre
- View all complaints
- Search/filter
- Verify
- Assign field staff
- Update status
- Dashboard analytics

Field Staff:
- Separate login
- Assigned work queue only
- Complaint details and evidence
- Add remarks
- Mark In Progress
- Mark Resolved
- Reopen

## Demo login
Citizen: citizen@ghmc.demo / citizen123
Admin: admin@ghmc.demo / admin123
Field Staff: field@ghmc.demo / field123

## Deployment
Upload index.html, styles.css and script.js to the root of a GitHub Pages repository.
No npm, Vite, React or external JavaScript libraries are required.
